Not an independently reusable component — TextField renders it for its `chips` slot.
category: Forms
role: internal
meta:
  title: TextFieldChips | astro-components HenriFournier.dev
  description: Renders a TextField's input chips inline with its input, and turns text into chips, moves them and submits their values.
parents: [TextField]

  - name: overflow
    type: '"wrap" | "scroll"'
    required: true
    description: TextField's `chipOverflow`, passed down to the ChipGroup.
  - name: name
    type: string
    required: false
    description: TextField's `name`, which each chip's hidden input submits under, in place of the text input.
  - name: removeLabel
    type: string
    required: false
    default: '"Remove"'
    description: TextField's `chipRemoveLabel`, the `removeLabel` of each ChipInput typed text becomes.
  - name: editLabel
    type: string
    required: false
    default: '"Edit"'
    description: TextField's `chipEditLabel`, the `editLabel` of each ChipInput typed text becomes.

  - name: default
    description: TextField's input.
    kind: any
  - name: chips
    description: The ChipInputs from TextField's `chips` slot.
