Use a text field with chips to collect several discrete pieces of information in one field, such as:

- the contacts a message goes to
- the terms of a search or a filter
- tags on an item

Each piece becomes an input chip people can check, edit and remove, and the form submits the chips, not the text.

### When not to use it

- **A single value:** use a [TextField](/components/text-field).
- **Choosing from a fixed set of options:** use [filter chips](/components/chip-filter), checkboxes or a menu, rather than typing them.
