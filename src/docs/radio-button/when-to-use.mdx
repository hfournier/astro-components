Use radio buttons to:

- select one option from a set
- show every available option at once

They work best for five options or fewer, stacked vertically, with one option selected from the start. Each option needs its own short label.

### When not to use it

- **More than one option can be chosen:** use checkboxes.
- **A single setting that turns on or off:** use a switch.
- **Many options, or little space:** consider a menu, though it takes more steps to choose from.
- **Nested choices:** don't nest radio buttons under other radio buttons.
