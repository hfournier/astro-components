  - name: href
    type: string
    required: false

    type: boolean

## Layout

From the start: the leading icon (or, on a checked item, the check, or else the icon's empty space when other items in the menu have an icon or a check), the label with its supporting text below it, the trailing text, the badge, the trailing icon, and on a parent item, the cascading indicator. See MenuItem for its sizes and colors.
