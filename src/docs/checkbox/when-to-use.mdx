Use checkboxes to:

- select one or more options from a list
- present a list with sub-selections, under a parent checkbox
- turn a single item on or off, on desktop

Checkboxes imply the options are related, and take less space than switches. Keep each label short and easy to scan.

### When not to use it

- **Only one option can be chosen:** use radio buttons.
- **A standalone setting that takes effect at once,** especially on mobile: use a switch.
