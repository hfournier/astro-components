Use a switch to:

- turn a single setting on or off
- start or stop something immediately, without a save step

Switches suit settings screens, stacked one above another, each with a short label that says what the switch does when it's on.

### When not to use it

- **The change waits for a save or submit:** use a checkbox.
- **Selecting several options from a list:** use checkboxes.
- **Choosing one option from a set:** use radio buttons.
- **Choosing between opposing options,** such as list view and map view: use a connected button group.
- **Starting an action:** use a button. People expect a call to action to be a button, not a switch.
