Slider is a native `<input type="range">`, so assistive tech announces its name, its role as a slider and its value. A range slider is two of them, one for each handle, each announced on its own. A vertical slider says so with `aria-orientation`.

Name every slider, usually with the text beside it: a `<label for>` pointing at its `id`, or `aria-labelledby`. Without visible text, give it `aria-label`. Assistive tech reads the name followed by the role, so say what the slider controls ("Volume", not "Slider"). Name each of a range slider's handles for the end of the range it sets, such as "Minimum price" and "Maximum price", in `handleStart` and `handleEnd`, and point both at the visible label with `aria-describedby` if there's one. When the value alone doesn't say enough, such as a temperature or a time, set `aria-valuetext` on the input to a fuller text ("21 degrees"), and update it with the value.

Keyboard interaction follows M3:

- **Tab** moves focus to the slider, which shows the theme focus ring around its handle. On a range slider, Tab goes from the start handle to the end one.
- **Arrow keys** move the value one step, or one stop with `showStops`. Right and up increase it; in right-to-left layouts, left increases it, following the track.
- An arrow with **Space** held moves it a larger interval: a tenth of the steps, from one to ten of them. With `showStops`, it moves one stop, as the arrows alone do.
- **Page Up** and **Page Down** move it the larger interval too, as Compose's sliders do. M3's table doesn't list them.
- **Home** and **End** set it to the minimum and maximum. A range slider's handle stops at the other one, so Home on the end handle sets it to the start handle's value.

The value indicator and the inset icon are decoration, hidden from assistive tech: the input's own value is what it announces.

The slider is at least 48px across its track, so it's a large enough target for touch. A press anywhere on it sets the value there, or a range slider's nearer handle, and dragging follows the pointer. Keep the stop indicators, or icons or text with 3:1 contrast at the slider's ends, so the ends of the inactive track are easy to find.
