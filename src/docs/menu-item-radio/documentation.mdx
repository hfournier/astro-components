## Choosing it

Choosing the item sets its `aria-checked` and clears the other radio items' in its MenuGroup (or in the menu, if it isn't in one), fires a `change` event on its Menu, whose `detail` is `{ name, value, checked: true }`, and closes the menu. Put each set of radio items in its own MenuGroup.

## Appearance

A checked item looks like a checked MenuItemCheckbox: a `tertiary-container` container with `on-tertiary-container` content (`tertiary` and `on-tertiary` in a vibrant menu), 12px corners all round, and a check in place of its leading icon.
