Use checkbox items for a List where any number of items can be selected, such as choosing sides or people to invite. M3 says to show selection with more than color, and the checkbox is that second cue beside the highlight.

### When not to use it

- **One choice only:** use ListItemRadio, as M3 says single-select lists shouldn't use checkboxes.
- **A setting that takes effect at once:** use ListItemSwitch.
- **An item that does something:** use a ListItem link or button.
