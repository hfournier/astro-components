Use a connected button group for a single-select or multi-select choice between a few closely related options, such as a view, a sort order or a set of filters. It replaces M3's segmented button.

- Keep every option in one style, so which ones are selected stays clear. The group sets one `variant`, `size` and `shape` for all of them.
- Let the group span the width of its page or surface. In a large window, give it a maximum width so it doesn't grow too wide.
- Keep a group to one line, with short labels. Stack separate groups to keep them close.

### When not to use it

- **Actions:** if none of the options are a choice to select, use a standard ButtonGroup of Buttons.
- **Many options or long labels:** use a list of RadioButtons or Checkboxes, or a Menu.
- **Turning one setting on and off:** use a Switch.
