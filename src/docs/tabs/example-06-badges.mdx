---
title: Tabs with Badges
description: Set a Tab's `badgeLabel` to show a Badge - a count, or `""` for a dot. On primary tabs with icons, the badge overlaps the icon; on secondary tabs, or tabs without icons, it follows the label. A count is added to the tab's accessible name, e.g. "Inbox, 3".
---

        </Tab>

    </Tabs>
