Use a chip group around every set of chips: M3 asks for chips to appear together, never one alone, spaced and wrapped the same way, and the group is what the arrow keys move within.

- Keep one kind of chip in a group, such as all filters or all suggestions.
- Wrap by default. Scroll when the set sits in a field one row high, or when filters would wrap past two rows.
- Keep every filter set on a page one kind: all multi-select, or all single-select.

### When not to use it

- **Buttons:** use ButtonGroup, or ButtonGroupConnected for a choice.
- **Many filters:** move them into a side sheet, as M3 suggests, rather than a long scrolling row.
