## Attributes

Every attribute goes on the `<div>`. Name the group with `aria-labelledby`, pointing at the visible label M3 asks for before a set of selectable chips, such as "Filter results", or with `aria-label`.

## Anatomy

- **Container:** invisible. It sets its chips inline as a row of options, 8px apart, M3's minimum space between chips, on both axes when they wrap.

A scrolling group pads its scroll box by 8px, the room each chip's 48px target and focus ring take beyond its edges, and takes it back with a negative margin, so its chips line up with what's around it.

## Keyboard

The arrow keys move between the chips that are the group's own children, so chips outside a ChipGroup don't get them. A single-select group's radios keep the browser's arrow keys instead, which move the selection.
