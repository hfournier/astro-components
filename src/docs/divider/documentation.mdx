  - name: inset
    type: '"none" | "start" | "middle"'
    required: false
    default: '"none"'
    description: How far the line stops short of its container's edges. `none` runs the full length. `start` leaves 16px at the start (before the line in a horizontal divider, above it in a vertical one), for example to line up with text that's indented past a leading icon. `middle` leaves 16px at both ends.
  - name: orientation
    type: '"horizontal" | "vertical"'
    required: false
    default: '"horizontal"'
    description: The direction of the line. A vertical divider stretches to the height of its row, so it needs a flex or grid parent, or a height class such as `h-6`. It's exposed to assistive tech with `aria-orientation="vertical"`.

## Full width and inset together

If a page uses both full-width and inset dividers, they should show its hierarchy: full-width dividers between different kinds of content, and inset dividers between the items nested within them.
