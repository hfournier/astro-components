## Attributes

Every attribute but `class` goes on the input, such as `name`, `value`, `disabled`, `form` and `aria-*`, so the chip submits with a form as any checkbox or radio does. On a menu chip, they go on its `<button>`. `class` goes on the chip.

## Flat or elevated

Use flat chips on plain backgrounds, where the outline marks the chip's edge. Use elevated chips only on an image or another busy background, where an outline would get lost.

## In a set

Show filters together, in a set, never one alone: put them in a [ChipGroup](/components/chip-group), below a label such as "Filter results" or under a search field, and name the group by that label with `aria-labelledby`. A set can wrap onto a second row; past two rows, give the group `overflow="scroll"` so it scrolls sideways, or move the chips into a side sheet.

Each chip is a checkbox, so any number can be selected. Listen for `change` and read the checked inputs, or let a form submit them.

## Single select

M3 also allows a set where selecting one chip deselects the others. Give the ChipGroup `selection="single"`, which makes it a radiogroup, and each ChipFilter in it `selection="single"` and the same `name`, which make them radios. Keep every set on a page one kind, all single-select or all multi-select, as M3 asks.

```astro
<ChipGroup aria-label="Size" selection="single">
  <ChipFilter selection="single" name="size" value="s">Small</ChipFilter>
  <ChipFilter selection="single" name="size" value="m" isSelected>Medium</ChipFilter>
  <ChipFilter selection="single" name="size" value="l">Large</ChipFilter>
</ChipGroup>
```

## With a menu

Give a chip `menuId` to open a Menu of options for one filter, such as a price range. The whole chip opens it, as M3 asks for compact windows, where a trailing icon alone is too small a target. Use MenuItemRadio items for one choice, or MenuItemCheckbox items for several.

The chip's label names the filter, such as "Price". With MenuItemRadio items, once an option is checked, from the start or by the person, the chip shows that option as its label, such as "Under $50", and takes the selected look. Give the option that clears the filter, such as "Any price", an empty `value`: checking it puts the filter's name back. With MenuItemCheckbox items, the label stays the filter's name, and the chip is selected while any option is checked. Listen for the menu's `change` event to apply the filter.
