## The control

BaseTextField can't see the control a component renders in its slot, so it hands the component what the control needs: a function in its default slot, which it calls with the control's attributes and classes and renders where the control goes (ADR-0032).

```astro
<BaseTextField variant={variant} id={id} layout="single-line" label={label} attrs={attrs} …>
  {(control: TextFieldControlType) => (
    <input class:list={twMerge(control.class, "h-6")} type={type} value={value} {...control.attrs} />
  )}
</BaseTextField>
```

Forward the icon, affix and supporting-text slots only when the page fills them. BaseTextField draws a part only when its slot has content, as a forwarded slot counts as present even when it's empty.
