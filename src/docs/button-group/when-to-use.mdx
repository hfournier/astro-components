Use a standard button group to keep related actions together and make them respond to each other: pressing one widens it and nudges its neighbours.

- Keep every button in a group the same size and shape. Use a different size only for a hero moment, and a different shape only when a button is selected or to add meaning.
- Vary the style, width or color to show which action matters most, such as one filled button among tonal ones.
- Keep a group to one line. On small windows, use smaller or narrower buttons, or move the trailing buttons into an overflow menu at the group's end. Stack separate groups to keep them close.

### When not to use it

- **Choosing between options:** for single or multi-select, use ButtonGroupConnected, the connected button group, which replaces the segmented button.
- **Standard icon buttons or text buttons:** they have no container to widen. Use filled, tonal, outlined or elevated ones.
- **Unrelated actions:** place those apart, so the group doesn't suggest a link between them.
