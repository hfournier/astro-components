## Placement

A FabMenu isn't positioned on its own, as with Fab: put it where the FAB belongs. M3 places it in the end (trailing) corner of the window, 16px from its edges, increasing to 24px on large windows. For example, `class="fixed inset-e-4 bottom-4 large:inset-e-6 large:bottom-6"` (`inset-e-*` keeps it in the trailing corner right to left). Keep it in the same corner at every window size, and use a larger FAB (`size`) on larger windows.

The items open upward from the FAB's top corner, 8px above it. The menu keeps the closed FAB's size while open, so nothing around it moves as the FAB turns into the close button.

The items are a popover, so they're drawn in the top layer: no ancestor's `overflow` or stacking order can clip or cover them. There's no scrim behind them, as in M3. Take care that they don't completely hide something interactive and its focus ring; covering part of it is fine.

## Short windows

When the window is too short for all the items, such as a phone in landscape, the list scrolls, as M3 specifies. It stays clear of the close button and 16px from the top of the window, with the top items showing first. It has no scrollbar: the cut-off item shows there's more, and moving focus to an item scrolls it into view.

## Large windows

M3's guidelines say that "on web, the FAB menu uses a menu component for an experience that's consistent with other desktop apps", and picture it in a large window beside the Expressive FAB menu on a compact one. So FabMenu switches at the large window size class (1200px):

- **Below 1200px** (compact, medium and expanded windows), it's M3 Expressive's FAB menu, as Jetpack Compose builds it, and as described above. Google's Material Web library doesn't implement M3 Expressive.
- **From 1200px**, the FAB opens a [Menu](/components/menu) of the same items, each a MenuItem with the FabMenuItem's icon and label. As M3's web specs say, it "inherits its states and specs from the baseline menu component": the vertical Menu, which M3 recommends for new designs. It opens 4px from the FAB, above it when the FAB is at the bottom of the window, lined up with the FAB's `align` edge, and keeps 48px from the window's edges. The FAB stays as it is while the menu is open, with the pressed state layer, rather than turning into a close button.

You write the items once. Choosing a MenuItem clicks its FabMenuItem, so the item's own `click` handlers and `command` run in either window. A `disabled` FabMenuItem is a disabled MenuItem, but other attributes, such as `aria-label` or `title`, stay on the FabMenuItem, so give each item its name through `label`. Only one form is shown, and exposed to assistive tech, at a time. Resizing across 1200px closes whichever is open, moving focus to the FAB now shown.

In large windows, M3 increases the FAB's margins from 16px to 24px, and recommends a larger FAB (see Placement).
