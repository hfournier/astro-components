Use a split button for a main action that has a few related ones, such as "Watch later" with "Watch tonight" and "Remind me". The main action stays one click away, and the others wait in a menu, which keeps the screen simple.

- Keep the leading button's label to one or two words, with the icon that best matches the action.
- Keep the trailing button's menu icon; it turns to show the menu opening.
- Open a Menu from it, and keep that menu ordinary. Its color and layout can follow Menu's own options.
- Use it beside buttons and icon buttons; it can be a different size from them, since it takes more space.

### When not to use it

- **One action:** use a Button.
- **A menu with no main action:** use a Button or ButtonIcon that opens the Menu.
- **Choosing between options:** use ButtonGroupConnected, or a Menu of radio items.
