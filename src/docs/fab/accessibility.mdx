The `label` is always the FAB's accessible name, whether or not it's visible. Use the same icon and label for the same action throughout. If you set your own `aria-label`, start it with the visible label's first word, such as `aria-label="Create a new invite"` for a visible "Create", so voice control users can say what they see (WCAG 2.5.3). The tooltip repeats it for sighted users while it's hidden, so the tooltip is hidden from assistive tech. It can be dismissed with Escape, and stays open while the pointer is over it, as WCAG 1.4.13 requires.
