## Placement

Use one FAB per screen, for its single most important action. A FAB isn't positioned on its own: it sits wherever you put it, such as in a NavRail's `fab` slot or fixed to a corner of the page (e.g. `class="fixed right-4 bottom-4"`). Use an extended FAB where a label makes the action clearer and there's room for it.

## In a NavRail

In a NavRail's `fab` slot, the rail decides whether the FAB is extended, as M3 specifies: extended while the rail is expanded, and a plain FAB while it's collapsed, whatever `isExtended` says. It follows the rail's width, using a container query on the rail, so it changes as the rail expands and collapses.
