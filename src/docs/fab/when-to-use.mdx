Use a FAB for a screen's primary, constructive action, such as create, compose, favorite, share or starting a process. Don't use one for minor, overflow or destructive actions, such as archive, delete or alerts. Give it a clear, filled icon, and a `label` that names the action, such as `"Compose a new message"`.

Use an extended FAB (`isExtended`) where a label makes the action clearer, or for more emphasis, such as on long scrolling screens like a checkout. Keep its label to one or two words, leaving room for longer translations. Don't use one as one option in a set of actions; use a filled Button there. Unlike a plain FAB, an extended FAB doesn't need an icon.
