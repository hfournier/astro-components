Use assist chips for smart or contextual actions that help with the current task, such as "Add to calendar" below an event, or "Get directions" below an address. They appear when the content calls for them, after the content they act on.

- Start the label with a verb, like a button's, and keep it short: 20 characters or fewer.
- Use a leading icon that identifies the action.
- Show chips in a set, never one alone.

### When not to use it

- **The main action, or a step forward in a flow:** use a Button. Chips offer side paths; buttons move a task on.
- **A suggestion the product made, such as a reply:** use ChipSuggestion.
- **Filtering a list:** use ChipFilter.
