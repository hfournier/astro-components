---
title: Badges
description: Set a NavBarItem's `badgeLabel` to show a Badge on its icon - a count, or `""` for a dot. As M3 asks, the badge sits on the icon's top-end corner at every width; from medium up, a large count reaches over the gap and the start of the label. A count is added to the item's accessible name, e.g. "Mail, 12", and a dot adds "New notification" (or the item's `badgeDescription`), e.g. "Chat, New notification".
