---
title: Badges
description: Set a NavBarItem's `badgeLabel` to show a Badge on its icon - a count, or `""` for a dot. Below the medium breakpoint (600px) the badge sits on the icon's top-end corner; from medium up, a count follows the label instead, so it doesn't cover it, and a dot stays on the icon. A count is added to the item's accessible name, e.g. "Mail, 12", and a dot adds "New notification" (or the item's `badgeDescription`), e.g. "Chat, New notification".
