Use a full-screen dialog for a task that needs the whole screen of a phone:

- a task with several steps, such as creating a calendar event with its title, date, location and time
- content that needs keyboard input, such as form fields
- changes that aren't saved straight away
- a task that opens other dialogs. Only a full-screen dialog can have another dialog over it.

M3 keeps full-screen dialogs to compact windows, such as phones. From a medium window up, DialogFullscreen is a basic dialog, like Dialog. It changes in CSS alone, so if the window is resized while it's open, its content, form values and focus stay where they are.
