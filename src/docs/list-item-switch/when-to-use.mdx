Use switch items for a List of settings that turn on or off, such as notifications or location. M3 says to use switches to toggle settings, with the switch at the end of the item.

### When not to use it

- **Choosing items:** use ListItemCheckbox for several, or ListItemRadio for one.
- **A setting that needs confirming before it applies:** use ListItemCheckbox in a form with a submit button, since a switch reads as taking effect at once.
