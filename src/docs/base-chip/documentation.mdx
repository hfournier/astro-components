## What the caller adds

BaseChip's label is on-surface. A chip whose label is another color, such as ChipSuggestion's on-surface-variant, gives its own `text-*` class, and the state layer and a focused flat outline follow it.

A chip the page makes draggable, with `draggable="true"`, shows M3's dragged state while it's dragged: elevation 4 and a 16% state layer. BaseChip doesn't add drag and drop itself.
