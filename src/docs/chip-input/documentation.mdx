## Attributes

Every attribute but `class` goes on the body, such as `disabled`, `draggable` and `aria-*`; the remove button takes `disabled` too. `class` goes on the chip.

## Selecting and removing

By default, a tap selects the chip and a second tap deselects it, as M3's Guidelines page describes: a selected chip is ready to remove. The chip's remove button, or Backspace or Delete on the focused chip, removes it. Before it goes, it fires a `remove` event, which bubbles and is cancelable: call `preventDefault()` to keep the chip, such as while asking for confirmation, or listen for it to drop the chip's value from your data. Once it's removed, focus moves to the next chip, or the previous one.

## Editing

With `isEditable`, a tap turns the chip back into its text, in a field that grows with it, as M3's Guidelines page shows for a mistyped email address. Enter, or leaving the field, commits the text; Escape puts the chip back as it was. A changed text fires a `change` event with `detail.value`, which bubbles and is cancelable: call `preventDefault()` to refuse it, such as an address without an `@`, which keeps the field open. Committing an empty field removes the chip.

```astro
<ChipGroup aria-label="To" id="recipients">
  <ChipInput isEditable>{"ziad@example.com"}</ChipInput>
</ChipGroup>
<script>
  document.getElementById("recipients")?.addEventListener("change", (event) => {
    const { value } = (event as CustomEvent<{ value: string }>).detail;
    if (!value.includes("@")) event.preventDefault();
  });
</script>
```

## Expanding

With `popoverId`, a tap opens that [Popover](/components/popover), to show more about the chip or offer options, as M3's Guidelines page shows for a contact. The chip shows its pressed state while the popover is open. Give the Popover `transition="container-transform"` for M3's container transform: it opens over the chip and grows out of it, and shrinks back into it as it closes.

## In a set

Put input chips in a [ChipGroup](/components/chip-group), which spaces them and moves between them with the arrow keys, or in a [TextField](/components/text-field)'s `chips` slot, inline with the cursor: text typed there becomes a chip, Backspace from the cursor selects the chip before it, chips move by dragging and with Shift and the arrow keys, and each chip submits with the form, its `value` attribute or else its label. An edit commits the new text to the `value` attribute too, when the chip has one.
