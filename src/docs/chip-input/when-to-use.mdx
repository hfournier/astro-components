Use input chips for discrete pieces of information a person entered, such as the contacts a message goes to, or the terms in a search field. They show the input was understood, as a name, a photo or an icon, and let people remove or correct each one.

- Lead with an avatar for a person, or an icon for a kind of thing; leave them off when the text says enough.
- Keep the remove button: M3 requires it on input chips.
- Make a chip editable when what was entered can be mistyped, such as an email address.
- Show the chips in a ChipGroup, together, never one alone.

### When not to use it

- **A filter the product offers:** use ChipFilter.
- **An action, such as "Add to calendar":** use ChipAssist.
- **A suggestion the product made, such as a reply:** use ChipSuggestion.
