Use list items for the entries of a List. Keep each one short and easy to scan:

- **Label:** brief, the item's name.
- **Supporting text:** one to three lines, more detail about the item.
- **Overline:** a category or a date above the label, where items are grouped by it.
- **Leading element:** a visual cue that relates to the label, anchored at the start so the list is easy to scan. Use an avatar for a person or an entity, an image for other content such as a product, a video thumbnail for a video, and an icon for a kind of thing.
- **Trailing element:** text for meta information, such as a price, a count or a date, or an icon for a status or where the item leads.

Make an item a link or a button when the whole item does one thing, such as opening a page. Leave it static when the list only shows information.

### When not to use it

- **More than one action in an item:** M3's multi-action items, with a button at the end beside the item's own action, aren't part of ListItem.
- **Selecting items:** M3's selection lists, with checkboxes, radio buttons or switches, are a separate kind of list.
