## Collapsed and expanded

In a collapsed rail, the item is M3's vertical rail item: the icon in a 56×32px active indicator, with the label in Label Medium 4px below it. In an expanded rail (wider than 160px), it's M3's horizontal rail item: the icon and the label, in Label Large, side by side 8px apart, in a 56px-high indicator that fits them with 16px either side. It follows the rail's width with a container query, so it changes as the rail expands and collapses. For sub-items, which M3 doesn't require to have icons, NavRailSubItems uses NavDrawerItem instead.

## Current page

NavRailItem marks itself as the current destination (`aria-current="page"`) when its `href` is the current page's path or a parent of it, so `href="/components"` is also current on `/components/button`. `href="/"` is only current on the home page, or it would match every page. In a collapsed rail, the current destination's icon sits in a pill-shaped active indicator in the secondary container color, and its label turns secondary; in an expanded rail, the indicator holds both, with `on-secondary-container` text. To decide this yourself, pass `aria-current`.

## Badges

`badgeLabel` adds a Badge, as in M3: a count, or a dot for `""`. In a collapsed rail, it sits on the top-end corner of the icon. In an expanded rail, a count follows the label instead, so it doesn't cover it, and a dot stays on the icon. Like the rest of the item, it follows the rail's width, so it moves as the rail expands and collapses. Each item anchors its badge to its icon with its own anchor name, so there's nothing to set up. Keep `badgeLabel` in step with the count it shows, since it also sets the item's accessible name: a count after the label ("Inbox, 3"), or `badgeDescription` for a dot ("Updates, New notification"). In a right-to-left page, the badge moves to the icon's top-left corner, its trailing corner there.
