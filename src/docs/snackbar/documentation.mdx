## Showing a snackbar

A snackbar is a manual popover. Show it with a button that has `commandfor` (its id) and `command="show-popover"`, or call `showPopover()` from a script, such as once a save finishes. To change the message first, set the text of its `[data-ac-snackbar-part="text"]` element.

Only one shows at a time. A snackbar asked to show while another is showing waits, and shows once the other one hides. To replace an outdated snackbar straight away, call `hidePopover()` on it first.

## Placement

It sits 12px above the bottom of the window. Below medium it spans the window, 12px from each side. From medium up it fits its text, up to 600px, at the start of the window. It starts past a navigation rail or drawer down that side, and goes up above a navigation bar or a FAB fixed to the bottom of the window. To place it elsewhere, such as centered, pass classes, and place it the same way each time.

## Writing

Write a short, clear update about the process, such as "Email archived". The action is a single verb that relates to it, such as "Undo" or "Retry".
