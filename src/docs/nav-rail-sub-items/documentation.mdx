## Where it goes

In a NavRail that isn't expandable, put the sections in a NavDrawer's default slot. In an expandable NavRail, put them in the rail's `sub-items` slot, with `slot="sub-items"` on each; they show at the end of the rail while it's expanded.

Every section renders, but only the current page's shows: the others have the `hidden` attribute. A NavDrawer swaps in the section of a rail item that's hovered or focused, fading the links out and in. A section only shows in a container named `rail` that's wider than 160px, which an expanded NavRail and a NavDrawer both are, so it doesn't show on its own.
