    type: SvgIconNameTypes
    required: false

## Leading and trailing elements

M3's anatomy has one leading element and one trailing one. The build fails on an item with more than one at either end, counting the control at its end: an icon, an avatar, an image, a video or a leading control before the label, and an icon, text or a trailing control after it.
