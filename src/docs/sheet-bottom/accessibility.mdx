The drag handle is the only part of the sheet with a label, and its role is button. As in Material's Jetpack Compose, it's named "Drag handle", and that name stays the same while it expands and collapses the sheet; its `aria-expanded` says which. A modal sheet with one height is different: its handle closes it, so it's named "Close" and has no expanded state. Pass `dragHandleLabels` to put these in the page's language.
