## Anatomy

As in M3 and Jetpack Compose, a bottom sheet is a container, an optional drag handle and, for a modal sheet, a scrim. It has no headline or close button of its own: what it holds is up to its content.

- **Naming it:** a modal sheet is a dialog, so it needs an accessible name. Give it an `aria-label`, or put a heading in its content and set the sheet's `aria-labelledby` to the heading's `id`. A standard sheet is a complementary landmark, which a name also helps tell apart.
- **Closing it at full height:** M3 asks for a close affordance in a modal sheet at full height, in an app bar in the sheet. Put a row at the top of the content with a close ButtonIcon that has `command="request-close"` and `commandfor` set to the sheet's `id`. Like Escape, it fires a cancelable `cancel` event. The scrolling example below shows one.

## When to use it

Use a bottom sheet for content and actions that support the page, not for its main content, in compact and medium windows. In a large window, put the same content in a SheetSide.

## Standard and modal

A standard sheet sits at the bottom of the main content, and both can be used at the same time. Put it last in a scrolling container (the page, or a scrolling region of it): it's sticky, so it stays at the container's bottom edge while the content scrolls behind it. Its drag handle collapses it to the handle alone, and expands it again.

A modal sheet slides up over the page, and the page under its scrim can't be used until it closes. Use one on a small screen for a set of choices that the user deals with before going back to the page. Examples are a share sheet, a menu with a long list of actions, or actions that need icons and longer descriptions.

Choosing an item or action in a modal sheet should close it. Give those buttons `command="close"`, a `value`, and `commandfor` set to the sheet's `id`. The sheet closes with its `returnValue` set to the value, so a `close` listener can tell which was chosen.

Use a standard sheet for content that complements the page while the page is still in use, such as an audio player, or details over a map. Collapsed, it shows only its drag handle.

## Heights

As M3 asks, a modal sheet opens at no more than half the window's height. If its content fits, that's its only height. If the content is taller, it scrolls inside that half, and the sheet gains a second, full height, the window's height less M3's top margin.

- **Changing height:** a click, Enter or Space on the drag handle toggles between the two heights, and the handle's `aria-expanded` says which height it's at. A drag up on it expands the sheet. A drag down returns it to half, and from half closes it.
- **Closing at full height:** the drag handle, Escape and the scrim still close it. Add a close button to the content too, as M3 asks (see Anatomy).
- **Each opening** starts at half height again.

## Labels

The drag handle is the only part of the sheet with a label, and its role is button. As in Material's Jetpack Compose, it's named "Drag handle", and that name stays the same while it expands and collapses the sheet; its `aria-expanded` says which. A modal sheet with one height is different: its handle closes it, so it's named "Close" and has no expanded state. Pass `dragHandleLabels` to put these in the page's language.

## Content

Lists, groups of actions separated by Dividers, and media all fit in a sheet. For a list of actions, use a `<ul>` of Buttons, with a Divider between groups.

## Layout

Following M3, the sheet spans the full width, up to 640px, centred, and in a window wider than 640px it also keeps 56px from the window's start and end edges. Its height follows its content, up to the window's height less a 72px top margin, or 56px in a window wider than 640px. A modal sheet is capped at half the window until it's expanded (see Heights). Past its cap, its content scrolls. It has extra-large (28px) top corners and sits at elevation 1. Its drag handle is 32 by 4px, centred in the sheet's top 48px.

The 640px maximum width can be changed with a class for a special case, such as `class="max-w-200"`. For a complex task in a large window, use a surface that stays on screen instead, such as a SheetSide or the page itself.
