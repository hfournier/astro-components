## Style by emphasis

Pick the style by how important the action is, from most to least emphasis:

- **Filled:** key, high-emphasis actions. Use it sparingly.
- **Tonal:** secondary actions next to a high-emphasis one.
- **Outlined:** medium-emphasis actions, such as moving through sets of cards.
- **Standard:** low-emphasis actions, or a button on a colorful surface.

When the button needs to stand out from its background, use filled, tonal or outlined rather than standard.

## Size and width

- Make the main action the most prominent, by color or size, as in play/pause or start/stop.
- Give buttons of similar importance the same size.
- Use only a few icon buttons at once. In dense layouts, group them in a toolbar or button group.

Don't shrink icon buttons to make a layout denser. Every size keeps a touch target of at least 48×48px (an invisible `::after` around the button), so don't override its size.

## Icons

A plain icon button uses a filled icon, such as `"star-fill"` rather than `"star"`.

A toggle uses the outlined icon while it's unselected and the filled one while it's selected, with `icon` and `selectedIcon` (`"bookmark"` and `"bookmark-fill"`). This isn't just style: M3 requires the selected state to show through at least two properties, not color alone. Without a filled version, M3 makes the icon bolder (semibold or bold). These icons are SVGs, so use a toggle only with an icon that has a filled version, or supply a bolder one as `selectedIcon`.

## Toggles

Use a toggle for a binary action that the button turns on and off, such as favorite, bookmark or mute. Don't use one for an action with no selected state, such as opening an overflow menu.

A button that shows and hides other content, such as a menu or a panel, isn't a toggle: leave out `isToggle` and give it `aria-expanded` instead, as MenuToggle does. Never use both on one button.

## Accessibility

An icon button has no visible text, so `label` is required: it's the button's accessible name, such as `"Delete"` or `"Add to favorites"`. Name the action, not the icon. The tooltip repeats the label for sighted users, so it's hidden from assistive tech. It can be dismissed with Escape, and stays open while the pointer is over it, as WCAG 1.4.13 requires.

A toggle keeps the same label whether it's selected or not (`"Bookmark"`, not `"Add bookmark"` / `"Remove bookmark"`), since screen readers announce the pressed state from `aria-pressed`. To react to a change, listen for the button's `click` event and read the new state from `aria-pressed`.

The default color roles meet M3's contrast requirement. If you change them, keep a contrast of at least 3:1 between the icon and its container, or the background behind it for a standard button.
