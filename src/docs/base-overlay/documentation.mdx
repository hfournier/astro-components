---
name: BaseOverlay
description: A primitive overlay component that renders as a native `<dialog>` or `<div popover>` element, providing shared open/close transition behavior for pattern components like Dialog and Popover.
category: Base
role: primitive
meta:
  title: BaseOverlay | astro-components HenriFournier.dev
  description: A primitive overlay component rendering as a native `<dialog>` or `<div popover>`, providing shared open/close transitions for Dialog and Popover.
extends:
  kind: element
  tag: [dialog, div]
props:
  - name: as
    type: '"dialog" | "div"'
    required: false
    default: '"dialog"'
    description: Which HTML element to render the overlay as. Any other value fails the build.
  - name: bgColor
    type: '"surface" | "surface-container-low" | "surface-container" | "surface-container-high" | "inverse-surface" | "tertiary-container"'
    required: false
    default: '"surface-container-high"'
    description: The Material 3 surface of the overlay's panel, limited to the surfaces M3 uses for overlays - `Surface` for full-screen dialogs, `Surface Container Low` for sheets and drawers, `Surface Container` for menus and rich tooltips, `Surface Container High` for dialogs, and `Inverse Surface` for plain tooltips and snackbars. The panel is a BaseWrapper, so text, links and focus rings inside it take matching colors. Any other value fails the build.
  - name: closedby
    type: '"any" | "closerequest" | "none"'
    required: false
    description: A `<dialog>`'s native `closedby` attribute, the user actions that close it. Dialog, DialogFullscreen and the modal sheets set `"any"`, so a click on the scrim closes them, as Escape does.
  - name: id
    type: string
    required: true
    description: Unique id for the overlay element, used to wire up command/commandfor triggers that open and close it. This is the native element's `id` attribute, but marked as required, instead of optional.
  - name: showBackdrop
    type: boolean
    required: false
    default: "true"
    description: Whether to render the dimmed `::backdrop` fill behind the overlay.
  - name: showBlur
    type: boolean
    required: false
    default: "false"
    description: Whether to blur the page content behind the overlay's `::backdrop`. Material 3 doesn't blur, so it's off by default.
  - name: transition
    type: '"fade" | "fade-down" | "fade-scale" | "container-transform"'
    required: false
    default: '"fade"'
    description: "Which enter/exit transition to apply when the overlay opens and closes. The `fade` transition is a simple fade-in/fade-out, `fade-down` also slides the overlay down into place, and `fade-scale` adds a scaling animation. `container-transform` approximates M3's container transform for a popover opened by a button, such as an input chip's: a `commandfor` button, or the one a page passes to `showPopover({ source })`. The popover opens over the button, top start corner to top start corner in the button's direction, or the corner it flips to near the window's edge, and grows out of the button's box, its content fading in after; closing, it shrinks back into the button, which takes focus back. Opened without a button, it's centred and fades. Under reduced motion it doesn't move, as the others. Any other value fails the build."
slots:
  - name: default
    description: The content to display inside the overlay.
    kind: any
---
