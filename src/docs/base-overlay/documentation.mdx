---
name: BaseOverlay
description: A primitive overlay component that renders as a native `<dialog>` or `<div popover>` element, providing shared open/close transition behavior for pattern components like Dialog and Popover.
category: Base
role: primitive
meta:
  title: BaseOverlay | astro-components HenriFournier.dev
  description: A primitive overlay component rendering as a native `<dialog>` or `<div popover>`, providing shared open/close transitions for Dialog and Popover.
extends:
  kind: element
  tag: [dialog, div]
props:
  - name: as
    type: '"dialog" | "div"'
    required: false
    default: '"dialog"'
    description: Which HTML element to render the overlay as.
  - name: bgColor
    type: '"surface-container-low" | "surface-container" | "surface-container-high" | "inverse-surface"'
    required: false
    default: '"surface-container-high"'
    description: The Material 3 surface of the overlay's panel, limited to the surfaces M3 uses for overlays - `Surface Container Low` for sheets and drawers, `Surface Container` for menus and rich tooltips, `Surface Container High` for dialogs, and `Inverse Surface` for plain tooltips and snackbars. The panel is a BaseWrapper, so text, links and focus rings inside it take matching colors.
  - name: id
    type: string
    required: true
    description: Unique id for the overlay element, used to wire up command/commandfor triggers that open and close it. This is the native element's `id` attribute, but marked as required, instead of optional.
  - name: showBackdrop
    type: boolean
    required: false
    default: "true"
    description: Whether to render the dimmed `::backdrop` fill behind the overlay.
  - name: showBlur
    type: boolean
    required: false
    default: "false"
    description: Whether to blur the page content behind the overlay's `::backdrop`. Material 3 doesn't blur, so it's off by default.
  - name: transition
    type: '"fade" | "fade-down" | "fade-scale"'
    required: false
    default: '"fade"'
    description: Which enter/exit transition to apply when the overlay opens and closes. The `fade` transition is a simple fade-in/fade-out, `fade-down` also slides the overlay down into place, and `fade-scale` adds a scaling animation.
slots:
  - name: default
    description: The content to display inside the overlay.
    kind: any
---
