Use radio items for a List where exactly one item is chosen, such as a size or a delivery option. M3 says to show selection with more than color, and the radio button is that second cue beside the highlight.

### When not to use it

- **Several choices:** use ListItemCheckbox, as M3 says multi-select lists shouldn't use radio buttons.
- **A few short options:** a connected button group, ButtonGroupConnected, takes less room.
