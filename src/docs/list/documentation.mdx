## Attributes

Every attribute goes on the `<ul>` or `<ol>`. Name a list with `aria-label` or `aria-labelledby` where a page has several and the name tells them apart, such as "Settings".

## Anatomy

- **Container:** invisible, with no padding. In the standard style its items paint M3's `surface` container, so a list on `surface` reads as one block. In the segmented style each item is its own `surface-container` container, 2px from the next.
- **Dividers:** between standard items, never below the last one. Each ListItem draws its own, hidden from assistive tech, so screen readers don't announce a separator between every item.

## Gaps and dividers

M3's Guidelines separate items and groups with gaps or dividers. Use gaps, the segmented style, for a contained list: its filled items and rounded ends mark it as one group. Limit dividers to uncontained lists, or lists complex enough to need a stronger separation than spacing. Use a full-width divider between items that stand apart, and an inset one between items of the same kind, so the line starts with the content.

## Segmented groups

A segmented List is one group. Its first item's top corners and its last item's bottom corners are 16px, the corners between items 4px, and an only item is 16px all around, as Compose's `segmentedShapes` rounds them. For several groups, such as messages by day, use a List for each, with a heading before it that names it through `aria-labelledby`. An item's own corners replace the group's while it's hovered (12px), focused or pressed (16px), or selected (16px). Put the list on `surface`, so its `surface-container` items stand out, as M3 draws them.
