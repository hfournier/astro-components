## Attributes

Every attribute goes on the `<ul>` or `<ol>`. Name a list with `aria-label` or `aria-labelledby` where a page has several and the name tells them apart, such as "Settings".

## Anatomy

- **Container:** invisible, with no padding. Its items paint M3's `surface` container, so a list on `surface` reads as one block, as M3's standard style shows.
- **Dividers:** between items, never below the last one. Each ListItem draws its own, hidden from assistive tech, so screen readers don't announce a separator between every item.

## Gaps and dividers

M3's Guidelines limit dividers to uncontained lists, or lists complex enough to need a stronger separation than spacing. Use a full-width divider between items that stand apart, and an inset one between items of the same kind, so the line starts with the content.
