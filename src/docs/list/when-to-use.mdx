Use a list to help people find a specific item and act on it, such as a contact, a setting or a file. M3's Guidelines ask for:

- **A logical order:** alphabetical or numerical, or by importance.
- **Short items that are easy to scan:** keep the label brief and the supporting text to one to three lines.
- **A consistent format:** put the same kind of leading element, text and trailing element in the same place in each item, so they line up.

A list of links to other pages, such as settings, is a single-action list: each item does one thing. A list that only shows information, such as a timeline, is non-interactive.

### When not to use it

- **Choosing among options:** M3's single- and multi-select lists, with radio buttons, checkboxes or switches, are a separate kind of list.
- **Rich content with room to show it:** at larger window sizes, M3 suggests cards or a carousel, which show the same elements with more space.
- **Running text:** a bulleted list in prose is a plain `<ul>`.
