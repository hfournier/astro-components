## Flat or elevated

Use flat chips on plain backgrounds, and elevated ones only on an image or another busy background.

## In a set

Show suggestions together, in a set, never one alone: put them side by side in one parent. The arrow keys move between the chips that share a parent. When the person picks one, act on it, such as sending the reply, and update or remove the set.
