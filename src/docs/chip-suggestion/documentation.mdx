## Flat or elevated

Use flat chips on plain backgrounds, and elevated ones only on an image or another busy background.

## In a set

Show suggestions together, in a set, never one alone: put them in a [ChipGroup](/components/chip-group), which spaces them as M3 asks and moves between them with the arrow keys. When the person picks one, act on it, such as sending the reply, and update or remove the set.
