Use suggestion chips to narrow what the person wants with suggestions the product generates, such as replies in a chat, or search terms related to what they typed.

- Keep each suggestion short: 20 characters or fewer.
- Show suggestions in a set, never one alone, and update them as the context changes.

### When not to use it

- **An action, such as "Add to calendar":** use ChipAssist.
- **Something the person entered, such as a contact:** use input chips.
- **The main action, or a step forward in a flow:** use a Button.
