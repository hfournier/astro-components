## Attributes

Every attribute except `class` and `maxlength` goes on the `<input>`, or the `<textarea>`: `name`, `value`, `placeholder`, `required`, `disabled`, `readonly`, `pattern`, `minlength`, `autocomplete`, `aria-*` and the rest. A textarea's `value` becomes its text. `class` goes on the element around the whole field, so it can place and size it. A field is 280px wide by default, Compose's minimum; set a width with `class`, such as `w-full`. Listen for the input's `input` or `change` event to react to a change.

`maxlength` is TextField's own soft limit, for its character counter (see the prop). The counter follows the person's typing and a form's reset. After setting the value from a script, dispatch an `input` event on the input so the counter follows it too. Past the limit, the input's validation message is "Use 20 characters or fewer" (with its limit), which the browser shows when the form is submitted.

A `placeholder` shows only while the field is focused and empty, since the resting label takes its place. Without a label, it always shows.

In MDX, leave a blank line between the label's text and each slotted element, or MDX puts them in one paragraph and the slots aren't found.

## States

- **Multi-line:** a growing field is 56px tall for one line and grows by Body Large's 24px a line; a text area is `rows` lines tall. The label rests on the first line, and the icons stay vertically centered, as M3's Specs page aligns them.
- **Enabled:** filled, a `surface-container-highest` container with a 1px `on-surface-variant` indicator. Outlined, a 1px `outline` outline. The label is `on-surface-variant` and the input text `on-surface`.
- **Hovered:** the indicator or outline turns `on-surface`, and the filled container shows an `on-surface` state layer at 8%. The outlined label turns `on-surface`.
- **Focused:** the filled indicator and the outline thicken to 3px `primary`, as M3's Specs page draws them, and the label turns `primary`. The caret is `primary`.
- **Error** (`aria-invalid="true"`, or the browser's own validation once the person has interacted): the indicator or outline, label, caret, trailing icon, supporting text and counter turn `error`, and hovered, the indicator, label and trailing icon turn `on-error-container`. See Accessibility.
- **Past the counter's limit:** the error state's colors, the counter's included, while the value is longer than `maxlength`.
- **Disabled** (`disabled`): everything in `on-surface` at 38%, the filled container at 4% and the outline at 12%.
- **Read-only** (`readonly`): styled as an enabled field, as M3 asks. Say it's read-only in its label or supporting text.

Both variants keep these roles on any background, as M3's Specs page maps them, so an outlined field inside a colored BaseWrapper still has an `on-surface-variant` label and supporting text and `on-surface` input text.

## Motion

M3's Specs page gives no timing, so TextField follows Compose: the label moves and resizes, the outline's gap opens, and the indicator or outline thickens on the fast spatial spring. Colors, the state layer, the prefix and the suffix fade on fast effects (ADR-0018). A growing multi-line field changes height on fast spatial as well, where Compose changes it at once, so its size moves on the spring M3 gives size changes. The placeholder fades in on slow effects as the field is focused, and out on fast effects. Under reduced motion, every state changes at once.
