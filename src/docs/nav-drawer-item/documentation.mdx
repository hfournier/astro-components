## Current page

NavDrawerItem marks itself as the current page (`aria-current="page"`) when its `href` is the current page's path or a parent of it, the same way as NavRailItem. The current page's link sits in M3's active indicator, a full-width pill in `secondary-container` with `on-secondary-container` text. With `activeIcon`, its icon also changes, to its filled version. Its label keeps the same weight, as in Compose's drawer item. Other links are `on-surface-variant`, turning `on-surface` while hovered, focused or pressed. Their state layer is in that color, except while pressed, when it's `on-secondary-container`, as M3's tokens set it. To decide which is current yourself, pass `aria-current`.

## Badge label

`badgeLabel` shows a count at the item's end, in Label Large: `on-surface-variant`, or `on-secondary-container` on the current page's link. It's plain text, not a Badge, as in M3's drawer. A long label is truncated before it, at least 12px away, so the count always shows in full.

## Layout

The item fills the width of its container, which in a NavDrawer is the drawer's width minus 12px either side, per M3. It's 56px high, with 16px either side of its content (28px from the drawer's edges, per M3), and 12px between the icon and the label.
