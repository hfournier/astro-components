## Current page

NavDrawerItem marks itself as the current page (`aria-current="page"`) when its `href` is the current page's path or a parent of it, the same way as NavRailItem. The current page's link sits in M3's active indicator, a full-width pill in `secondary-container` with `on-secondary-container` text. Other links are `on-surface-variant`, turning `on-surface` while hovered, focused or pressed. To decide which is current yourself, pass `aria-current`.

## Layout

The item fills the width of its container, which in a NavDrawer is the drawer's width minus 12px either side, per M3. It's 56px high, with 16px either side of its content (28px from the drawer's edges, per M3), and 12px between the icon and the label.
