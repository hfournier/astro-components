## Anchoring

By default the badge is `position: fixed`, anchored to the element it decorates, so it can go anywhere in the markup and isn't clipped by that element's `overflow`. With `placement="inline"` it's an ordinary inline element instead, and needs no anchor.

The badge follows the anchor named in its `--ac-anchorname-badge` custom property. Give the element it decorates a matching `anchor-name`. Anchor names are dashed idents, and each must be unique on the page:

```astro
<Icon class="[anchor-name:--inbox-badge]" name="inbox" label="Inbox, 3 unread" />
<Badge class="[--ac-anchorname-badge:--inbox-badge]" label={3} />
```

## Accessibility

A badge is visual only: it's always rendered with `aria-hidden="true"`, since screen readers would otherwise read its count on its own ("3") with no context. Put the full meaning in the decorated element's accessible name instead, such as Icon's `label="Inbox, 3 unread"`, and keep the two in sync whenever the count changes.

Use Icon's `label` prop rather than a raw `aria-label`: without `label`, Icon adds `aria-hidden="true"`, which hides the `aria-label` too.
