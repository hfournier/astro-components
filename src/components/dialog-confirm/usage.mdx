---
title: DialogConfirm
description: The following example shows how to use the DialogConfirm component, specifying the required `id`, `buttonDismiss`, and `buttonConfirm` properties, along with an optional `headline`.
---

<Button command="show-modal" commandfor="dialog-confirm-usage">Open Confirm Dialog</Button>

<DialogConfirm
  id="dialog-confirm-usage"
  headline="Discard draft?"
  buttonDismiss={{ text: "Cancel", value: "cancel" }}
  buttonConfirm={{ text: "Discard", value: "discard" }}
>
  Your unsaved changes will be lost.
</DialogConfirm>
